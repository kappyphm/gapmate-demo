# Senior Backend Engineer — Sample JD

**Company:** Demo Cloud Inc.
**Location:** Remote (Vietnam)
**Level:** Senior
**Employment:** Full-time

## About the role

We are looking for a Senior Backend Engineer to design and scale our microservice platform.

## Responsibilities

- Design, build and maintain REST and gRPC APIs.
- Own service reliability, performance and observability.
- Work with PostgreSQL and Redis at scale.
- Deploy services to AWS using Docker and Kubernetes.
- Drive CI/CD automation and code quality through reviews.
- Mentor junior engineers.

## Required

- 5+ years of backend development experience.
- Strong Python (FastAPI or Django) AND Node.js/TypeScript.
- Deep knowledge of PostgreSQL and SQL optimization.
- Hands-on Docker and Kubernetes.
- Experience with AWS (EC2, S3, Lambda).
- Solid understanding of microservices and event-driven design (Kafka is a plus).
- CI/CD with GitHub Actions.

## Nice to have

- Terraform / Infrastructure as Code.
- gRPC.
- Data pipeline experience (Airflow, Spark).

## Benefits

- Fully remote, flexible hours.
- Competitive salary and stock options.
